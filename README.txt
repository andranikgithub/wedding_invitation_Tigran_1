ՄԿՐՏՈՒԹՅԱՆ ՀՐԱՎԻՐԱՏՈՄՍ — FLASK

1. Բացիր PowerShell-ը այս թղթապանակում։
2. Գրիր՝ py -m venv venv
3. Գրիր՝ .\venv\Scripts\Activate.ps1
4. Գրիր՝ pip install -r requirements.txt
5. Գրիր՝ py app.py
6. Բացիր՝ http://127.0.0.1:5000
